# Career Ops — AI 求职工作台

本地 AI 驱动的求职工具。你只管输入原始资料，AI 负责结构化、分析、生成。所有数据保存在你的电脑上。

## 核心思想

```
你(自然语言 / 文本 / URL) → 前端(采集 + 展示) → 后端(编排 + AI + 存储)
```

**你只做三件事：** 输入资料 → 点按钮触发 AI → 查看结果。
**所有复杂逻辑都在后端：** AI 调用、数据格式化、校验去重、冲突合并。前端不做任何业务判断。

三种驱动方式：

| 标签 | 含义 |
|------|------|
| `[手动]` | 你操作 |
| `[AI]` | 你触发，AI 完成 |
| `[自动]` | 系统自动处理 |

---

## 安装与启动

**你需要：** Node.js 18+、Chrome 或 Edge 浏览器

**双击 `start-gui.bat`** 即可启动。首次运行会自动安装依赖。浏览器打开 `http://localhost:5173`。

其他脚本：
- `restart-gui.bat` — 页面异常时重启
- `stop-gui.bat` — 彻底关闭，释放端口

## 快速上手

### 1. 健康检查 `[自动]`

打开应用后，在工作台点击「运行检查并安装依赖」，等所有项变绿。

### 2. 配置 AI `[手动]`

进入「设置」页，配置 AI 接口：

- **DeepSeek** — 填入 API Key（[注册地址](https://platform.deepseek.com/)）
- **豆包/火山方舟** — 填入火山方舟的 API Key

API Key 只存在你本机的 `.env` 文件中。

### 3. 录入简历 `[手动]` + `[AI]`

进入「简历」页。两种方式：

- **AI 批量导入（推荐）：** 把你所有资料（旧简历、项目描述、技能列表）粘贴进去，AI 自动提取结构化数据，智能合并已有信息
- **手动填写：** 分模块录入基本信息、教育、经历、项目

### 4. 开始找工作

推荐流程：

```
设置简历 → 搜索岗位 → AI 评分 → 生成定制简历 → 投递追踪 → 面试准备
```

## 七个页面

### 工作台 `/`

`[自动]` 全局概览。已发现岗位数、有效岗位数、推荐投递数、待跟进数、项目健康状态。每天打开看一眼。

### 简历 `/resume`

`[手动]` + `[AI]` 维护你的简历资料库。

| 操作 | 驱动 | 说明 |
|------|------|------|
| AI 批量导入 | `[AI]` | 粘贴任意文本（旧简历/项目描述/技能列表），AI 提取结构化数据并智能合并 |
| 逐模块编辑 | `[手动]` | 修改基本信息、教育、经历、项目、技能、获奖 |
| 预览简历 | `[自动]` | 实时渲染 Markdown 预览 |
| 生成 PDF | `[AI]` | 选择目标岗位，AI 生成定制简历，输出到 `output/` |

**核心理念：** 同一套完整资料，针对不同岗位由 AI 自动删减、强化对应的项目和技能，生成多个版本的简历。

### 岗位 `/jobs`

`[手动]` + `[AI]` 岗位的发现、导入、筛选、评分。**使用频率最高的页面。**

**导入岗位（三种方式）：**

| 方式 | 说明 |
|------|------|
| 粘贴 URL | 你粘贴官网岗位链接，系统自动抓取 |
| AI 搜索 | 填专业方向、城市、企业性质，AI 从多平台搜索 |
| 拖拽 JSON | 导入结构化岗位数据 |

**对选定岗位的操作：**

| 操作 | 说明 |
|------|------|
| 提取 JD | `[自动]` 从 URL 抓取岗位描述正文 |
| AI 优化 JD | `[AI]` 重新整理 JD 结构和关键信息 |
| AI 评分 | `[AI]` 匹配度打分（1-5），含匹配亮点、缺口分析、简历策略 |
| 加入投递 | `[手动]` 将岗位加入投递追踪 |
| 面试准备 | `[AI]` 跳转到面试页生成准备材料 |

筛选栏支持按「有效/已关闭/未确认」过滤岗位。未确认 = 原候选区缓冲。

### 投递 `/tracker`

`[手动]` + `[自动]` 双 Tab 页面。

**投递记录 Tab：** `[手动]` 管理投递状态流转（已评估 → 已投递 → 已回复 → 面试中 → 已录取/已拒绝），备注记录渠道、联系人、面试轮次。

**跟进提醒 Tab：** `[自动]` 系统根据投递状态和时间自动计算跟进节奏，按紧急度分四级（紧急/逾期/等待中/已冷却），按卡片点击筛选。`[手动]` 标记已跟进，记录跟进消息。

### 面试 `/interview`

`[手动]` 选择岗位触发，`[AI]` 生成完整面试准备材料。

生成内容：匹配度雷达评分、技术面试题、项目深挖题、行为题、公司研究、项目讲法建议、反问面试官的问题。

勾选跟踪准备进度。重点岗位深度使用即可。

### 公司 `/companies`

`[手动]` 维护目标公司库。配置名称、关键词、排除词、地点。公司数据可自动从岗位导入中提取。

### 设置 `/settings`

`[手动]` 配置 AI 提供商 API 密钥。AI 功能不正常时首先检查这里。

## 数据格式规范

AI 生成的所有数据遵循统一的渲染规范：

| 字段类型 | 数据格式 | 展示效果 |
|----------|----------|----------|
| 文本 | 字符串 | 单行文本 |
| 标签 | `R, Python, SQL` | 标签云 |
| 列表 | `内容1；内容2；内容3` | 圆点列表 (按中文分号拆分) |
| 日期 | `YYYY-MM` | 格式化日期 |
| 实体 | JSON 数组 | 独立卡片 |

**关键规则：** 描述性内容用中文分号（；）分隔每个短句，不要用句号或换行。日期统一 `YYYY-MM` 格式。

## 常见问题

**启动后页面打不开？**
- 确认两个服务都在运行（后端 3001，前端 5173）
- 双击 `restart-gui.bat` 重启

**AI 功能无反应？**
- 进入设置页检查 API Key 是否配置且有效
- 检查网络是否能访问 DeepSeek/火山方舟 API

**PDF 生成失败？**
- 确认已安装 Chrome 或 Edge
- 运行健康检查，缺失时会自动安装 Playwright Chromium

**数据保存在哪？**

| 内容 | 路径 |
|------|------|
| 岗位、公司 | `data/job-radar/` |
| 投递记录 | `data/applications.md` |
| 跟进记录 | `data/follow-ups.md` |
| 评分报告 | `reports/` |
| PDF 简历 | `output/` |
| 面试准备 | `interview-prep/` |
| AI 配置 | `.env` |
